## 免备案服务器“免”的是什么，不免的又是什么

免的是中国大陆的 ICP 备案流程。服务器放在香港或海外，不在工信部的备案管辖范围内，买完解析域名就能访问，这是它最大的价值。

不免的东西有两样，买之前最好知道。

第一是内容监管。海外服务器上的网站如果内容违规，工信部可以通过屏蔽 IP 或屏蔽域名的方式，让大陆用户打不开。阿里云那篇讲免备案主机优缺点的文章写得很直白：网站有被封的风险。免备案不等于没人管。

第二是速度和稳定性。访问速度受服务器位置影响，这是物理规律。香港节点对大陆用户延迟低，美国节点慢一截，欧洲更远。三丰云在自家免备案服务的说明里也承认，免备案服务走的是海外线路，“由于国家防火墙的原因在稳定性和速度方面不如国内主机”，建议用户备案后改用国内线路。这话从一家卖免备案服务的商家嘴里说出来，可信度反而高一些。

还有一条资料里提到、但很少有人当回事的：小型服务商可能撑不下去。价格低到不合理的商家，跑路、失联、数据拿不回来，这类事在低价 VPS 圈子里不算新闻。长期用的机器，商家活得久比配置高更重要。

## 下单前要确认的五件事

**机房到底在哪。** “免备案”的前提是服务器不在大陆。有些商家卖的所谓“国内免备案空间”，机房实际在大陆，靠 CDN 加速绕过备案，这种产品的合规风险要自己掂量。

**续费价是多少。** 首月、首年的促销价和续费价经常差一倍以上。买之前把续费价找出来，按两年的总成本算一遍。

**能不能换 IP。** 海外服务器 IP 被墙是常事。Vultr 的做法是删除重建、换一个新 IP；萤光云资料里写的是免费换 IP 两次；腾讯云需要看具体产品规则。换 IP 要不要钱、麻不麻烦，直接影响出事后的恢复速度。

**退款和试用政策。** 萤光云标的是 5 天无理由退款，其他商家各不相同，有的不支持退款。第一次用某家，尽量月付试一个月。

**支付方式和实名要求。** 国内厂商购买通常需要实名认证，海外商家大多不需要，但可能要求信用卡。先确认自己付得了款，再谈配置。
